# सूर्य कुंज आवासीय योजना — वेबसाइट

## जानकारी भरना
`index.html` खोलें, सबसे ऊपर `window.INFO = { ... }` में मोबाइल नंबर, WhatsApp नंबर, फ़र्म का नाम,
कार्यालय का पता, UP RERA पंजीकरण संख्या, Google Maps लिंक और मूल्य भरें। बाकी पूरी साइट अपने-आप भर जाएगी।

## फ़ाइलें
- index.html — मुख्य वेबसाइट
- 3d.html — 3D भ्रमण
- walkthrough.mp4 — वॉक-थ्रू वीडियो
- plan.png, *.jpg — चित्र

## GitHub Pages पर चालू करना (RERA नंबर मिलने के बाद)
1. GitHub पर नया public repo बनाएँ (जैसे `surya-kunj`) और ये सारी फ़ाइलें उसमें डालें।
2. Settings → Pages → Branch: main, फ़ोल्डर: / (root) → Save।
3. कुछ मिनट में साइट `https://<username>.github.io/surya-kunj/` पर खुल जाएगी।
